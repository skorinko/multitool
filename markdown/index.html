Markdown Viewer turns every Markdown file you open in Safari into a clean, readable page. Click a link that ends in .md and you get formatted text instead of raw markup, styled like GitHub, in light or dark mode to match your device.

Diagrams

Mermaid code blocks render as diagrams: flowcharts, sequence diagrams, Gantt charts, pie charts and more. Click any diagram to open it full screen, then pinch or scroll to zoom and drag to move around. A diagram with a mistake shows the error and its source, never a blank space.

Made for long documents

A contents sidebar lists every heading and highlights the section you are reading. Heading links work, so a link to #installation jumps straight there. Footnotes link down to their notes and back.

Turn it on

On a Mac

  1. Open Safari Settings and choose Extensions.
  2. Tick Markdown Viewer.
  3. Click Edit Websites… and set it to Allow on every website, so files open formatted everywhere.

On iPhone and iPad

Turn it on in Settings

  1. Open Settings, then Apps, then Safari.
  2. Tap Extensions, then Markdown Viewer.
  3. Turn on Allow Extension.
  4. Under Permissions, set All Websites to Allow, so files open formatted everywhere.

Or from Safari

  1. Open a Markdown file and tap the page menu button beside the address.
  2. Tap Manage Extensions and turn on Markdown Viewer.
  3. Tap Markdown Viewer in the same menu, then Always Allow… and Always Allow on Every Website.
