Page Unlocker gives Safari back what websites take away. Right-click shows Safari’s menu again, text can be selected and copied, passwords and email addresses can be pasted into forms, and pages print as they look. It works as pages open: there is nothing to click.

Keeps web apps working

Many unlockers break the sites that use these features themselves. Page Unlocker tries a page’s own handling first and steps in only when it blocks. File managers, maps and editors keep their right-click menus; fields that split a pasted code into boxes keep doing it; Google Docs, Figma, Notion, Slack and other web apps are left alone unless you turn it on for them.

See what each page blocked

The toolbar button counts what a page tried to block, and its menu lists each item: right-clicks unblocked, selection locks removed, pastes let through. If a page still resists, one click switches it to Strong mode, which also lifts invisible layers laid over text and pictures.

  • Leaves web apps' own menus and editors working
  • Shows what each page blocked, and what was undone

Turn it on

On a Mac

  1. Open Safari Settings and choose Extensions.
  2. Tick Page Unlocker, then choose Always Allow on Every Website.
  3. That's all: pages unlock as they open. Press ⌃⇧U to switch a site between Standard, Strong and Off.

Page Unlocker needs access to the websites you visit so it can unlock them as they open. Nothing leaves your Mac.

On iPhone and iPad

Turn it on in Settings

  1. Open Settings, then Apps, then Safari.
  2. Tap Extensions, then Page Unlocker.
  3. Turn on Allow Extension, then set All Websites to Allow.

Then, on any web page

  1. Pages unlock as they open: touch and hold text to select and copy it.
  2. To see what a page blocked, or to change the mode, tap the page menu button beside the address, then Page Unlocker.

Page Unlocker needs access to the websites you visit so it can unlock them as they open. Nothing leaves your device.
