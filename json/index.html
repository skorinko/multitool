JSON Prettifier Free

Readable JSON in Safari, exact to the last digit.

Coming soon to the App StoreTry it in Safari

Free with Multitool. Mac, iPhone and iPad.

JSON Prettifier turns the wall of text an API sends back into a tidy tree you can fold, search and copy from. Open a JSON address, click the button, and read it.

Never loses a digit

Most viewers read numbers the way JavaScript does, so 9007199254740993 quietly becomes 9007199254740992. JSON Prettifier shows every number exactly as it was sent, and tells you when a document has such numbers. Keys stay in the order the server wrote them, and repeated keys are pointed out.

What it does

  • A fast tree you can fold, search and filter, even for very large documents
  • Exact numbers, clear errors with line and column, JSON Lines and JSONPath
  • Copy paths and values, save, and paste JSON into the Scratchpad

Turn it on

On a Mac

  1. Open Safari Settings and choose Extensions.
  2. Tick JSON Prettifier. It needs no access to your websites until you turn on automatic formatting.
  3. On a JSON page, click the JSON Prettifier button in the toolbar, then Format This Page, or press ⌃⇧F.

JSON Prettifier reads a page only when you ask, or when it is JSON and automatic formatting is on. Nothing leaves your Mac.

On iPhone and iPad

Turn it on in Settings

  1. Open Settings, then Apps, then Safari.
  2. Tap Extensions, then JSON Prettifier.
  3. Turn on Allow Extension.

Then, on any web page

  1. Tap the page menu button beside the address, then JSON Prettifier, then Format This Page.
  2. To format every JSON page by itself, turn on Format JSON pages automatically there.

JSON Prettifier reads a page only when you ask, or when it is JSON and automatic formatting is on. Nothing leaves your device.
