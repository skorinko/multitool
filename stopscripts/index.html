Stop JavaScript on the websites you choose.

Some websites are better without their scripts: no “ad blocker detected” walls, no pop-ups asking for your email, no videos starting by themselves, no page that jumps while you read. Safari can only turn JavaScript off everywhere. Stop All Scripts turns it off on the websites you choose, and leaves every other website as it is.

Every script, not just some

Content blockers can stop script files, but not the scripts written into the page itself, which is where many overlays come from. Stop All Scripts stops them all, before the first one runs.

JavaScript when you need it

Some pages need a script for one thing: a search box, a comment form, a video. Let JavaScript run on that website for 10 minutes, an hour or the rest of the day, and it stops again by itself.

What it does

  • Stops inline scripts, script files, event handlers and frames
  • One switch per website, and JavaScript for 10 minutes when you need it
  • Pages stay readable: fallback content and pictures still show

Turn it on

On a Mac

  1. Open Safari Settings and choose Extensions.
  2. Tick Stop All Scripts, then choose Always Allow on Every Website.
  3. On a website, click the Stop All Scripts button and turn the switch on. Or press ⌃⇧J.

Stop All Scripts needs access to the websites you visit so it can stop their scripts before they start. Nothing leaves your Mac.

On iPhone and iPad

Turn it on in Settings

  1. Open Settings, then Apps, then Safari.
  2. Tap Extensions, then Stop All Scripts.
  3. Turn on Allow Extension, then set All Websites to Allow.

Then, on any web page

  1. Tap the page menu button beside the address, then Stop All Scripts.
  2. Turn the switch on. The page reloads without its scripts.

Stop All Scripts needs access to the websites you visit so it can stop their scripts before they start. Nothing leaves your device.
